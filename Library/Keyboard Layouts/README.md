# Arabic Buckwalter keyboard layout

`ArabicBuckwalter.keylayout` maps the ASCII [Buckwalter transliteration][bw] to
Arabic script, one keystroke per letter — type `ktb` and get `كتب`.

Generated by `gen_keylayout.py`. Edit the generator, re-run it, and re-run
`install.sh` — do not hand-edit the `.keylayout`:

```sh
python3 "Library/Keyboard Layouts/gen_keylayout.py" > "Library/Keyboard Layouts/ArabicBuckwalter.keylayout"
```

`install.sh` copies (does not symlink) every `.keylayout` here into
`~/Library/Keyboard Layouts/`; HIToolbox does not reliably load symlinked
layouts. Enable it under System Settings → Keyboard → Text Input → Input
Sources → Edit… → + → Others → Arabic Buckwalter.

| | | | `k` | ك | | `` ` `` | ٰ |

Extended Buckwalter (Persian/Urdu): `P` پ, `J` ژ, `V` ڤ, `G` گ.

Keys with no Buckwalter meaning (`c`, `e`, `B`, `C`, `I`, `L`, `M`, `O`, `Q`,
`R`, `U`, `W`, `X`, digits, and unlisted punctuation) pass through as ASCII, so
a stray Latin letter marks a mistyped transliteration. Caps Lock acts as Shift
for letters. Command and Control combinations stay Latin, so ⌘C/⌘V/⌘Z work.

## Option layer

Arabic punctuation and digits, kept off the base layer so Buckwalter round-trips
exactly:

| Combination | Output |
|---|---|
| ⌥1 … ⌥0 | ١٢٣٤٥٦٧٨٩٠ |
| ⌥, ⌥; ⌥/ ⌥. | ، ؛ ؟ ۔ |
| ⌥[ ⌥] | « » |
| ⌥⇧5 ⌥⇧= ⌥⇧7 ⌥⇧8 | ٪ ٫ ٬ ٭ |
| ⌥⇧1 ⌥⇧2 | ZWNJ, ZWJ |
